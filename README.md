# Al-Burhan Website

Next.js portfolio website for AL-BURHAN ISLAMIC HERBAL MEDICINE CENTRE LTD.

## Run locally

Install dependencies, then run bun run dev or npm run dev.

The site includes the supplied Al-Burhan logo and product images under public/al-burhan/, with pages for the home experience, company story, services, and contact details.

## Sanity placeholder

The standalone Studio is in the sibling studio-al-burhan folder. Frontend environment placeholders are in .env.example; add real Sanity values to .env.local when you are ready to connect content.
